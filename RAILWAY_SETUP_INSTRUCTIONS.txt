═══════════════════════════════════════════════════════════════════
  STEP 1: UPDATE RAILWAY START COMMAND
═══════════════════════════════════════════════════════════════════

Go to Railway Dashboard:
1. Click your Django service (Banelo-Forecasting-DirectPostgre-main)
2. Go to "Settings" tab
3. Find "Custom Start Command"
4. Change it to:

python manage.py migrate && python manage.py ensure_admin && python manage.py runserver 0.0.0.0:8080

This will:
  ✓ Create database tables (migrate)
  ✓ Create admin user automatically (ensure_admin)
  ✓ Start the server
